# V1 verified release and notification gate

V1 READY is a distinct milestone, not the end of the full program. Do not issue it before every condition passes:

- SW-001..SW-012 accepted with reviewed/merged code and traceable PR/commit evidence; no critical/high unresolved defects.
- Actual Windows 11 x64 normal-user machine launched packaged executable and passed required Shell-default handlers, web links, keyboard hotkeys, tray, floating Dock, multi-monitor/DPI, theme switching, local profile export/import, offline startup and unavailable UNC handling.
- Unit, integration, import-security, contract/schema and performance checks executed and pass. Logs identify machine/OS, timestamps and versions. An autogenerated consistency check alone is not proof.
- Published GitHub release has downloadable portable Windows x64 asset, release notes, WebView2/runtime requirements and exactly matching SHA256 digest. Fresh download and execution verified.
- `releases/v1/readiness.json` accurately contains PASS, test evidence, artifact checksum, release and direct asset URL, verification UTC timestamp, and limitations.

When verified, notify once: **Smart Workspace Launcher V1 ready — Windows tested**. Include release URL, direct asset URL, SHA256, evidence for Windows acceptance tests, installation instructions, code-signing disclosure and known limitations. Update release-tracking issue and status. Do not label source-only ZIP, speculative build or Linux-only tests ready.

Proceed immediately through SW-013..SW-025 (V1.1, V1.2, V2.0) after V1 notification. Each later release repeats Windows packaging, QA and publication gates. If Windows testing is not available, label release BLOCKED, request required environment, and continue feasible cross-platform tasks.
